Waypoint is an independent, open-source fork of Hydra maintained by kjhq. It stores game-save snapshots directly in your Google Drive, without a Hydra subscription or a separate save-storage server.

Development status: public-release qualification is in progress. No stable release is available yet. Keep an independent copy of important saves when testing.

Backup history you control

Connect Google in your browser, create manual backups, and opt individual games into automatic sync. Backups appear in a visible Waypoint Saves folder. Snapshot history preserves conflicting progress for you to choose; it does not merge game files automatically.

Windows, Linux, and Steam Deck

Desktop and Big Picture interfaces are included. Platform qualification remains in progress. Existing game catalogues, downloads, and other Hydra services remain separate from Google Drive save storage.
