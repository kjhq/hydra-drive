Support

Report bugs in kjhq/hydra-drive issues. Include your app version, operating system, the operation that failed, and the visible error. Redact account identifiers and private file paths. Never attach Google tokens or OAuth authorization codes.

Connection problems

Open Settings → Cloud saves, then reconnect your Google account. Development OAuth clients accept only configured test users; stable public distribution is still being qualified. If a sign-in session expires, start Connect again from the launcher.

Conflicting saves

Compare devices and timestamps before choosing a snapshot. Choosing one does not merge game files. Keep an independent local copy when testing a development build.

Moving from official Hydra

Waypoint backs up saves already on your device. If a save exists only in Hydra Cloud, restore it using official Hydra first. Add your games to Waypoint, connect Google Drive, and turn on sync for each game you want to back up automatically.

Private enquiries

Email arvintro@gmail.com for privacy or security concerns. This community project does not promise a support response time.
